# “智巡开源”项目方案

## 一、问题与目标

校园实验室和小型机房普遍依赖人工巡检，存在间隔长、异常发现慢、视频隐私风险和商业平台成本高的问题。本项目以 ESP32-C3 和 Milk-V Duo 256M 两级 RISC-V 开源硬件构建全天候巡检节点，在现场完成 AI 识别与多传感器判断，将平均异常响应时间控制在 3 秒以内。

## 二、核心功能

1. 人员活动与禁入时段识别。
2. 温湿度、烟雾和功耗实时监测。
3. 多模态风险融合，降低单传感器误报。
4. 本地声光告警与平台消息提醒。
5. 节点状态、事件记录和告警处置看板。
6. 断网继续巡检，恢复连接后补传事件。

## 三、创新点

- **隐私计算**：原始视频不出现场，仅上传目标类别、置信度和时间等结构化结果。
- **边缘自治**：规则引擎位于现场节点，平台不可用时仍能告警。
- **多模态融合**：视觉疑似烟雾与 MQ-2 浓度共同判断，减少光照和水汽造成的误报。
- **模块化开放接口**：统一 MQTT 主题与 JSON 事件格式，便于增加门磁、漏水和噪声传感器。
- **RISC-V 异构协同**：ESP32-C3 负责低功耗感知与本地告警，Milk-V Duo 256M 负责 Linux 边缘视觉推理，实现 MCU 与边缘 AI 的分工协同。
- **开源硬件交付**：同步发布固件、接线定义、BOM、边缘融合程序及后续开源载板设计规范。

## 四、验收指标

| 指标 | 目标值 |
|---|---:|
| 端侧单帧推理延迟 | ≤ 80 ms |
| 事件到告警延迟 | ≤ 3 s |
| 人员检测准确率 | ≥ 90% |
| 常规场景误报率 | ≤ 5% |
| 断网自治巡检 | ≥ 24 h |
| 连续稳定运行 | ≥ 72 h |

## 五、实施计划

- 第 1 周：硬件采购、接线和传感器标定。
- 第 2 周：完成 ESP32-C3 感知节点和 Milk-V Duo 256M 边缘节点联调，采集场景数据并部署轻量视觉模型。
- 第 3 周：完成 MQTT 通信、规则引擎与管理看板。
- 第 4 周：使用嘉立创 EDA 或 KiCad 完成载板设计，导出原理图、Gerber、BOM 和坐标文件，并进行系统指标测试。

## 六、答辩演示脚本

先展示全部节点在线和实时数据；随后触发“模拟异常”，说明端侧在 3 秒内完成判断并产生告警；进入告警中心完成处置；最后断开网络，展示蜂鸣器仍可触发，突出边缘自治和隐私保护。
