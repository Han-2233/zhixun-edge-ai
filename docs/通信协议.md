# MQTT 通信协议

## 主题

- 遥测上报：`zhixun/nodes/{nodeId}/telemetry`
- 事件上报：`zhixun/nodes/{nodeId}/events`
- 指令下发：`zhixun/nodes/{nodeId}/commands`
- 在线状态：`zhixun/nodes/{nodeId}/status`

## 遥测消息示例

```json
{
  "nodeId": "SEN-02",
  "timestamp": 1789084800000,
  "temperature": 24.6,
  "humidity": 48,
  "smokeRaw": 318,
  "power": 12.8,
  "danger": false
}
```

## 事件消息示例

```json
{
  "eventId": "evt-20260912-001",
  "nodeId": "CAM-01",
  "type": "restricted_area_intrusion",
  "severity": "high",
  "confidence": 0.964,
  "message": "非开放时段检测到人员活动"
}
```
